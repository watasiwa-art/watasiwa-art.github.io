## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/watasiwa-art/watasiwa-art.github.io.git
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build project

```bash
npm run build
```
